# Placement Drive Manager

Placement Drive Manager is a web application designed for placement cells to manage employer records, placement drives, and recruitment analytics.

## Tech Stack

- **Framework**: TanStack Start / React
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Database / Auth**: Supabase
- **Icons & UI**: Lucide React & Radix UI

## Getting Started

### Prerequisites

- Node.js (v18+)
- npm or bun

### Local Setup

1. Clone the repository:
   ```sh
   git clone git@github.com:ashwelfernandes631-ctrl/Placement-drive-manager.git
   cd Placement-drive-manager
   ```

2. Install dependencies:
   ```sh
   npm install
   ```

3. Set up environment variables:
   Create a `.env` file in the root directory:
   ```env
   VITE_SUPABASE_URL=your_supabase_url
   VITE_SUPABASE_PUBLISHABLE_KEY=your_supabase_publishable_key
   ```

4. Start development server:
   ```sh
   npm run dev
   ```

5. Build for production:
   ```sh
   npm run build
   ```
